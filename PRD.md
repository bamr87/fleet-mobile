# Product Requirements Document (PRD): fleet-mobile

> Kotlin Multiplatform app to monitor the bamr87 fleet's bots, CI and PRs from a phone.

Open work is tracked in [GitHub Issues](https://github.com/bamr87/fleet-mobile/issues) and as `status: planned` entries in [features/features.yml](features/features.yml).

## 1. Overview

The fleet console in your pocket: shared Kotlin logic for Android and iOS showing bot runs, CI status and PRs waiting on review.

| Version | Date | Notes |
| --- | --- | --- |
| 0.1 | 2026-10-28 | Initial requirements and phased roadmap (repo foundation). |

## 2. Goals

- Shared KMP core that reads fleet status (hub _data / GitHub API)
- Compose Multiplatform UI for Android and iOS
- Push notifications for failing CI and PRs needing review

Non-goals (near term): production hosting, paid services, anything outside the roadmap below without a PRD change.

## 3. Users

- The maintainer, learning kotlin multiplatform architecture, compose multiplatform ui by building.
- Fleet agents (hub evolution loop, backlog fan-out, `evolve` lane) that grow the repo one reviewed PR at a time.
- Fleet tie-in: Mobile front end for the hub console, harness registry and fleet activity log; signs in through zer0-id.

## 4. Requirements

Phases are the build order: an agent picks the earliest unserved requirement first.

### 4.1 Phase 1 — Foundation

- FR1: Shared Kotlin module with a fleet status model and unit tests (JVM target)
- FR2: Gradle build of the shared module in CI

### 4.2 Phase 2 — Core

- FR3: Ktor client fetching hub fleet data
- FR4: Android app shell with a repo status list

### 4.3 Phase 3 — Fleet integration

- FR5: iOS target and Compose Multiplatform UI
- FR6: Notifications for failing CI and review requests

### 4.4 Non-functional

- NFR1: CI (`.github/workflows/ci.yml`, the fleet standard gate) passes on every PR.
- NFR2: No secrets or credentials are committed; configuration comes from environment variables.
- NFR3: Autonomous lanes are off by default, open pull requests only, and never merge.
